# RDB GeoMind · 锐多宝出品

**为中文遥感人做的 QGIS 智能助手——说人话，干地信活。**

在 QGIS 里用中文自然语言指挥干活的智能体插件，由锐多宝 RDB（四川锐多宝科技有限公司）开发。

你用中文描述想做的处理，GeoMind 调用大模型理解指令、生成一份**可预览的执行计划**，你核对后点「确认执行」才会真正运行；计划里的每一步都是明确的 GIS 工具调用，执行日志与新建图层全程可见。没有现成工具能完成的特殊需求，GeoMind 会生成一段脚本作为「脚本计划」——**脚本必须由你单独确认后才会执行**，出错时自动给出回滚提示，并可让模型按报错修正一版（修正版仍需再次确认）。

## 功能

- **智能对话面板**（停靠窗口）：中文聊天、对话历史、执行计划预览区、执行日志区。
- **多服务商大模型接入**：OpenAI 兼容接口，内置 DeepSeek、通义千问（DashScope 兼容模式）、智谱 GLM、Kimi（Moonshot）预置，也可填任意自定义 base_url。API Key 由你自己填写、只存本机设置、只发往你选择的服务商。
- **21 个内置 GIS 工具**：加载矢量/栅格、列出图层、图层样式（单色/分类/透明度）、重投影、按掩膜裁剪、影像镶嵌、波段计算、波段合成、分区统计、缓冲区、属性连接、空间连接、字段计算、几何有效性修复、按属性提取、融合、矢量合并、导出图层、缩放至图层、出图版面导出。工具参数在执行前按 schema 校验，缺参或不合规直接中文报错拦下。
- **10 种预置遥感指数**：NDVI、NDWI、NDBI、EVI、SAVI、NDMI、MNDWI、GNDVI、NDRE（红边）、BSI，每种都标注公式出处与波段口径，点名即算。
- **13 个工作流模板（不耗对话次数、不用大模型）**：影像裁剪、影像镶嵌、批量重投影、波段合成与指数计算、分区统计、出图排版导出（标题/指北针/比例尺/图例/纸张/分辨率全部参数化），加上国产/主流卫星处理链——高分一号/二号 PMS、高分六号红边指数链、吉林一号、哨兵二号（带 SCL 云掩膜）、Landsat 8/9 地表温度单窗简化链，波段映射按各传感器公开口径预置好，选星即用；另有多时相指数合成与两期变化检测两个通用模板。填参数一键生成计划，与智能体计划共用同一套确认与执行引擎。
- **安全执行模型**：先预览后执行；脚本步单独确认；失败即停并列出本次新建图层给出回滚建议；脚本支持一次「按报错自动修正」。
- **脚本审阅与会话留档（整改阶段一新增）**：脚本步悬停预览带行号，并对删文件、联网、启动外部进程等常见高风险写法给出中文风险标注（只提示、不拦截）；对话页可一键把本会话的对话、计划与执行记录导出为 Markdown 文件（存本机 `~/.rdb_geomind/history/`），便于留档与售后排查。
- **核心与 QGIS 解耦**：全部核心逻辑只依赖 Python 标准库，可在无 QGIS 环境下无头测试（仓库 tests/ 即如此运行）。

## 安装

1. 下载发布包 `rdb_geomind-<版本>.zip`（或在本仓库运行 `python3 build_zip.py` 自行打包，产物在 `dist/`）。
2. 打开 QGIS 3.28+，菜单「插件 → 管理并安装插件 → 从 ZIP 安装」，选择 zip 文件。
3. 启用插件后，右侧出现「RDB GeoMind · 智能助手」停靠面板（也可从菜单/工具栏打开）。

## 设置

在面板「设置」页：

1. 选择模型服务商（或「自定义」填任意 OpenAI 兼容地址）；
2. 填你自己的 API Key 与模型名，点「保存设置」；
3. （可选）在「授权码」处粘贴 Pro 授权码并点「验证授权码」，保存后状态栏显示 Pro 类型（月付显示到期日，永久版显示「永久版」）。

免费版每日次数计数保存在本机 `~/.rdb_geomind/usage.json`，跨日自动重置，只记次数不记对话内容。

## 使用

- **智能对话**：在对话页用中文描述任务 → 查看计划预览（工具步逐条列明参数）→ 点「确认执行」。若计划中出现「脚本·待确认」步，先选中该步、检查脚本内容（悬停可见全文），点「确认所选脚本步」，再确认执行。
- **工作流模板**：在模板页选模板、填参数（图层名填工程中已有图层名，多个用英文逗号分隔）→ 生成计划 → 回对话页确认执行。

## 已知局限

- 本版本在无 QGIS 的环境中完成开发：核心引擎经 FakeBackend 全量测试，QgisBackend 与界面层通过语法与接口核对，尚未在真实 QGIS 中逐项实机验证（见 `测试记录.md`）。
- 脚本执行不是安全沙箱：脚本等同于你在 QGIS Python 控制台亲自运行的代码，这正是脚本步必须单独确认的原因。
